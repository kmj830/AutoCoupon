# ⚽ FC 온라인 쿠폰 자동 수집 & 무인 등록 시스템 (AutoCoupon)

인터넷 커뮤니티와 공식 홈페이지에서 실시간으로 발행되는 **FC 온라인 쿠폰 코드를 5분마다 자동으로 수집**하고, 등록된 **넥슨 계정에 무인으로 자동 등록**해 주는 확장프로그램입니다.

### 🚀 확장 프로그램 1분 설치 방법 (Chrome / 웨일 / Edge 공통)
1. 브라우저 주소창에 `chrome://extensions` (웨일은 `whale://extensions`, 엣지는 `edge://extensions`) 입력 후 이동합니다.
2. 우측 상단의 **[개발자 모드]** 스위치를 **ON(켜짐)**으로 바꿉니다.
3. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]**를 누르고 **`FCOnline_AutoCoupon_Extension`**(또는 압축 푼 폴더)를 선택합니다.
4. **설치 끝!** 평소처럼 넥슨에 로그인되어 있으면 브라우저가 켜져 있는 동안 **5분마다 백그라운드에서 무음으로 자동 등록**됩니다.

## 🌟 주요 특징

1. **5분 무음 백그라운드 자동 등록 (Task Scheduler)**:
   * 5분마다 조용히 실행되어 신규 쿠폰을 등록합니다.
2. **다중 소스 실시간 크롤링 (인벤 + 에펨코리아 + Cloudflare 백엔드)**:
   * **에펨코리아** FC 온라인 쿠폰 게시판
   * **인벤** 팁과 노하우 쿠폰 탭
   * **Cloudflare Workers 백엔드 서버**를 통한 실시간 수집.
