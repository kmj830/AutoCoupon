# ⚽ FC 온라인 쿠폰 자동 등록기 (크롬 확장 프로그램)

평소 사용하시는 웹 브라우저(Chrome, 네이버 웨일, Edge)에서 **넥슨 로그인 세션 튕김 현상 0%**로 5분마다 실시간 쿠폰을 자동 등록해 주는 초경량 확장 프로그램입니다.

---

## 🌟 특징
* **세션 튕김 0%**: 평소 브라우저에서 넥슨에 로그인되어 있는 상태를 그대로 사용하여 등록하므로 다른 기기/프로그램 간 로그아웃 핑퐁이 전혀 없습니다.
* **5분 주기 백그라운드 자동 수집**: 5분마다 중앙 서버에서 최신 쿠폰(인벤, 에펨코리아, 공식 공지)을 조회하여 자동으로 등록합니다.
* **무음 백그라운드 처리**: 사용자가 웹 서핑이나 게임을 하고 있어도 방해 없이 백그라운드에서 조용히 처리됩니다.
* **실시간 브라우저 토스트 알림**: 새 쿠폰 등록 성공 시 우측 하단 팝업으로 즉시 안내합니다.

---

## 🚀 1분 설치 방법 (Chrome / 웨일 / Edge 공통)

1. **브라우저 확장 프로그램 관리 페이지 접속**
   * **크롬(Chrome)**: 주소창에 `chrome://extensions` 입력 후 엔터
   * **네이버 웨일(Whale)**: 주소창에 `whale://extensions` 입력 후 엔터
   * **엣지(Edge)**: 주소창에 `edge://extensions` 입력 후 엔터

2. **개발자 모드 켜기**
   * 페이지 우측 상단의 **[개발자 모드]** 스위치를 **ON(켜짐)**으로 바꿉니다.

3. **확장 프로그램 로드**
   * 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
   * 이 프로젝트의 **`extension`** 폴더를 선택합니다. (`C:\Dev\AutoCoupon\extension`)

4. **설치 완료!**
   * 브라우저 상단 퍼즐(확장 프로그램) 아이콘을 눌러 **[FC 온라인 자동 쿠폰]**을 고정(핀 📌)해 두시면 언제든 상태와 등록 내역을 확인할 수 있습니다.

---

## 💡 사용 방법
* 평소처럼 크롬에서 [FC 온라인 공식 홈페이지](https://fconline.nexon.com/main/index)에 로그인해 두시기만 하면 끝입니다!
* 이후 브라우저가 켜져 있는 동안 **5분마다 자동으로 새 쿠폰을 감지하여 등록**합니다.
